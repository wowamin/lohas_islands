# 3D 城市全面視覺重構

## 檢查與參考圖分析

現有權威資料在 `src/game/board.ts`、`rules/boardRules.ts`、`cityLayout.ts`；80 格與事件、存檔遷移已具備。主 WebGL 場景是 `District/CareIsland.tsx`，實際模型由 `islandModel.ts` 產生；不是 React Three Fiber 的備用場景。Zustand 在 `game/store/`，規則在 `game/rules/engine.ts`，2D 在 `UI/CityMap.tsx`。

目前主要視覺差距：底座過薄、格子是小圓片、五中心共用同一棟建築、外圍山景搶走城市焦點、UI 佔據過多畫面。這些需要改造模型與構圖，不能靠背景圖片取代。

參考圖 1：厚實切片底座、分層屋頂與窗框、石岸河道、木橋、複合樹冠、柔光。參考圖 3：七區彩色圓角地磚、明確的 80 格單向動線、圍繞城市的玩家／回合／事件介面。參考圖 2：補充蜿蜒地形與路線節奏，避免其高飽和配色。所有圖片編號只作視覺提示，資料依程式唯一 1–80 編號。

## 實作順序

1. 棋盤與地形：厚浮島、多層土壤與圓角邊緣、彩色立體格、路線碰撞驗證。
2. 五中心：獨立屋頂／立面／入口／坡道／招牌與庭院，保留原角色。
3. 環境：分區櫻花與闊葉樹、街屋、河岸石牆、低成本水面、木橋、長椅與涼亭。
4. 光影：校正日夜曝光、減少泛白、共用粗糙度與玻璃／水材質、接觸陰影。
5. UI：左側玩家、上方回合、上方視角切換、下方骰子與路線進度、右側事件；手機重排。
6. 相機與動畫：正交等角總覽、跟隨、自由探索、事件與終點平滑聚焦。
7. 驗收：遊戲回歸、真實模型測試、3D／2D 切換、完整旅程、存檔、桌面／手機尺寸與建置。

保留既有格子 ID、事件與邏輯位置，以及五中心庭院座標；入口與終點只做必要的間距調整，不改存檔索引。重複物件共享幾何／材質並批次實例化；中文標示保留清晰的既有 DOM 投影文字。只使用真正的 Three.js 幾何，不使用整張參考圖作場景。不得自動發布正式站。

## 效能與資源管理

每個城市生命週期共用幾何與材質，靜態網格按幾何／材質批次合併為 InstancedMesh，並保留逐實例中心點選資訊。五中心完整模型仍可點選。低／中／高畫質約 232 個靜態批次、2356／2807／3079 個實例；實際 draw calls（含陰影、角色與畫質差異）記錄於 `artifacts/diorama-review.json`。

桌面 Chrome 本機量測低畫質約 30 FPS，中高約 60 FPS；詳見 `artifacts/diorama-review.json` 的 DPR 與三角形紀錄。這些結果屬桌面硬體，不代表實體手機。動態 DPR 範圍最低 .75，最高依原畫質設定與裝置像素比；避免在低 FPS 時只維持高解析度。五個內庭使用不同高度的台地與連接坡道，外圈棋盤步道高度保持一致。

骰子小視窗共用原骰子模型、相同動畫 token 與 Zustand 點數，不建立新的亂數結果；靜止時只在狀態變化時重繪。切換為 2D 時釋放這個 WebGL 預覽，保留原 SVG 點數顯示。所有新增幾何、材質、紋理、實例、RAF、控制器及 renderer 在切換或卸載時釋放。

## 尚未實機驗證與預覽

尚未驗證實體手機、Safari、不同 GPU 或低階裝置；手機目前僅 Chrome 尺寸模擬。圖像參考是美術方向，交付物為可旋轉的程式化 3D 微縮模型，並非逐像素複製參考圖。

本機執行 `npm.cmd run dev -- --host 127.0.0.1`，開啟終端顯示網址。正式預覽用 `npm.cmd run preview -- --host 127.0.0.1`。先建置後可跑 `npm.cmd run test:diorama` 和 `npm.cmd run test:journey`。

本次只在 `feature/80-tile-city-board` 分支修改與驗證，沒有推送、合併或發布正式網站。
